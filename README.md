# clothes-theft-tracker
# 👗 Clothes Theft Investigation Unit

> *for every girl whose sister has zero respect for boundaries.*

---

## 🚨 The Problem

My sister steals my clothes. Constantly. Unapologetically.

After the 12th incident, I stopped arguing and started documenting.

## 🔍 What It Does

A case-file style tracker to log, monitor, and build evidence against your clothes thief — because someone has to.

- **Log items** by category (dress, top, jacket...)
- **Mark as STOLEN** when it happens (again)
- **Track return rate** — spoiler: it's low
- **Verdict updates** based on offense count
- **Upload a mugshot** of the suspect

## 🎮 Built With

- HTML / CSS / JavaScript
- Zero frameworks. Zero dependencies. Just chaos and a grudge.
